# `# Quiz Management System` 

# `## 1. Project Overview` 

```
A desktop application for creating multiple-choice questions and conducting
quizzes with automatic score calculation.
```

```
This project is designed as a simple college-level Python desktop application.
It uses a graphical user interface built with Tkinter and stores data locally
using SQLite. The application is intended for demonstration, academic
submission, and basic practical use.
```

# `## 2. Main Objectives` 

- `Create and store multiple-choice questions.` 

- `Allow users to take quizzes through a graphical interface.` 

- `Calculate scores automatically.` 

- `Provide immediate result feedback.` 

- `Reduce manual checking of quiz answers.` 

# `## 3. Main Modules` 

- `Question Management` 

- `Question Deletion` 

- `Quiz Attempt` 

- `Answer Evaluation` 

- `Score Calculation` 

# `## 4. Technologies Used` 

```
- Programming Language: Python 3
```

- `GUI Framework: Tkinter` 

- `Database: SQLite3` 

- `Programming Style: Event-driven desktop application`
